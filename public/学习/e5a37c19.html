可对角化与特征值

  • 4.4 可对角化的情况

    • 三种表达方式

      • 变量替换：把「原来的变量」换成「好的变量」，逐个击破
      • 坐标变换：y(t)=Cr(t)\mathbf{y}(t) = C\mathbf{r}(t)y(t)=Cr(t)，其中 CCC 是变换矩阵
      • 乘方计算：At=PDtP−1A^t = PD^tP^{-1}At=PDtP−1

    • 用矩阵语言表达坐标变换

      • 原问题 r(t)=Ar(t−1)\mathbf{r}(t) = A\mathbf{r}(t-1)r(t)=Ar(t−1)
      • 令 y(t)=Cr(t)\mathbf{y}(t) = C\mathbf{r}(t)y(t)=Cr(t)，则变成 y(t)=CAC−1y(t−1)\mathbf{y}(t) = C A C^{-1}\mathbf{y}(t-1)y(t)=CAC−1y(t−1)
      • 如果 CAC−1=DC A C^{-1} = DCAC−1=D 是对角矩阵，问题就归结为 4.3 的标量情形
      • 还原时用 r(t)=C−1y(t)\mathbf{r}(t) = C^{-1}\mathbf{y}(t)r(t)=C−1y(t)

    • 为什么不能用初等变换

      • 通过初等行/列变换确实能把 AAA 变成 diag\mathrm{diag}diag 形式
      • 但初等变换是在 AAA 的左右两边分别乘以可逆矩阵 CCC 和 PPP，得到 CAP=DCAP = DCAP=D
      • 而这里的变量替换要求：左边的 r(t)\mathbf{r}(t)r(t) 和右边的 r(t−1)\mathbf{r}(t-1)r(t−1) 必须经过同一个 PPP 变换
        • 即 r(t)=Py(t)\mathbf{r}(t) = P\mathbf{y}(t)r(t)=Py(t) 在递推式两边同时生效
      • 所以初等变换在这里不适用 —— 这是第 2 章里「无所不能」的初等变换在本章失效的原因

    • 4.5 特征值、特征向量

      • 几何意义

        • 乘以 A=(1.3000.3)A = \begin{pmatrix} 1.3 & 0 \\ 0 & 0.3 \end{pmatrix}A=(1.30​00.3​) 之后，只有长度的伸缩变化而方向保持不变的向量就是 AAA 的特征向量
        • 伸缩倍率就是特征值（伸长时为 1.3，缩短时为 0.3）

      • 定义：满足 Ap=λpA\mathbf{p} = \lambda \mathbf{p}Ap=λp 的非零向量 p\mathbf{p}p 是特征向量，λ\lambdaλ 是对应的特征值

      • 旋转矩阵没有实特征向量

        • A=(0−110)A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}A=(01​−10​) 把 (1,0)T(1,0)^T(1,0)T 转到 (0,1)T(0,1)^T(0,1)T，把 (0,1)T(0,1)^T(0,1)T 转到 (−1,0)T(-1,0)^T(−1,0)T
        • 对应「以原点为中心逆时针旋转 90 度」的变换
        • 所有向量都转了 90 度，方向不变的向量找不到 → 实数范围内没有特征向量
        • 引入复数后就有了：特征值 +i+i+i 的特征向量 p+=(1,i)T\mathbf{p}_+ = (1, i)^Tp+​=(1,i)T，特征值 −i-i−i 的是 p−=(1,−1)T\mathbf{p}_- = (1, -1)^Tp−​=(1,−1)T
        • 所以即便是实矩阵，特征值和特征向量也可能是复数

      • 复特征值的情况

        • 一般的实方阵 AAA（若可对角化）用实矩阵 PPP 变换后得到分块对角的实矩阵 DDD
        • 每个 2×22 \times 22×2 区块对应一对共轭复特征值
        • 求分块对角矩阵的幂，只需对各区块分别求幂

特征值的两种理解

第一种：伸缩倍率。

Ap=λpA\mathbf{p} = \lambda\mathbf{p}Ap=λp 意味着沿 p\mathbf{p}p 这个方向，映射只做伸缩。λ>1\lambda > 1λ>1 伸长，∣λ∣<1|\lambda| < 1∣λ∣<1 缩短，λ<0\lambda < 0λ<0 伸缩加翻转。

第二种：系统失控的判据。

第 4 章的真正目标是判断 r(t)=Ar(t−1)\mathbf{r}(t) = A\mathbf{r}(t-1)r(t)=Ar(t−1) 会不会失控。如果 AAA 可对角化成 A=PDP−1A = PDP^{-1}A=PDP−1，那么

At=PDtP−1A^t = P D^t P^{-1}At=PDtP−1

失控与否完全由 DDD 的对角元素决定，也就是由 AAA 的特征值决定：

  • 存在 ∣λ∣>1|\lambda| > 1∣λ∣>1 → 失控

  • 所有 ∣λ∣<1|\lambda| < 1∣λ∣<1 → 不失控

  • 所有 ∣λ∣≤1|\lambda| \le 1∣λ∣≤1 但有 ∣λ∣=1|\lambda| = 1∣λ∣=1 → 仅凭特征值无法判断

这个判据是全书最有实用价值的结论之一：不用算完整的 AtA^tAt，只要算出特征值。

为什么特征值是「固有的」

书中明确指出：DDD 的对角元素本质是特征方程的解，是矩阵本身的固有性质，没有任何人为操作的余地。

这解释了为什么变量替换得到的 DDD 的对角元素是确定的 —— 你换基底、换变量方式都不会改变它们。换句话说，特征值是矩阵的不变量。

从特征值到 Jordan 标准型

特征值判据有个漏洞：∣λ∣=1|\lambda| = 1∣λ∣=1 的情况，仅凭特征值无法判断。

原因是当 AAA 不可对角化时，AtA^tAt 里有 ttt 这个因子出现。一个 λ=1\lambda = 1λ=1 的 Jordan 块，其 ttt 次方带上 ttt 的增长，ttt 无限增大时还是会发散。

这就是下一节（4.7 不可对角化的情况）要解决的问题：用 Jordan 标准型补上这个缺口。
