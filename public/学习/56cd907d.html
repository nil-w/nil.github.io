LU 分解

  • 3.3 LU分解

    • 核心思想

      • 把矩阵 AAA 分解成 A=LUA = LUA=LU
        • LLL 是下三角矩阵，对角线全为 1
        • UUU 是上三角矩阵
      • 消元法的每一步操作都对应着一个矩阵，LLL 就是这些操作的累积
      • 分解的巧妙之处：LLL 和 UUU 可以拼接成一个矩阵存储
        • 左下部分存 LLL，右上部分存 UUU，对角线是 UUU 的
        • 大小和原矩阵 AAA 相同，所以可以在 AAA 自己的存储空间上覆盖
        • LLL 对角线的 1 和 UUU 对角线以下的 0 完全不用存

    • 3.8 意外发生的情况：选主元

      • 如果消元过程中主元为 0，就无法顺利分解成 A=LUA = LUA=LU
      • 办法是交换行，对应左乘一个置换矩阵 SSS
      • 多次选主元的结果：A=PLUA = PLUA=PLU
        • P=S1S2…SkP = S_1 S_2 \dots S_kP=S1​S2​…Sk​
        • 每一行恰好一个 1、每一列恰好一个 1、其余为 0 的矩阵叫置换矩阵
        • 置换矩阵乘以向量，效果就是重新排列分量的顺序
        • 任何置换矩阵都能写成若干 SSS 的乘积

    • 3.6 利用LU分解求解线性方程组

      • 把 LUx=yLU\mathbf{x} = \mathbf{y}LUx=y 翻译一下：先乘以 UUU，再乘以 LLL
      • 于是分两步
        1. 求满足 Lz=yL\mathbf{z} = \mathbf{y}Lz=y 的 z\mathbf{z}z
        2. 求满足 Ux=zU\mathbf{x} = \mathbf{z}Ux=z 的 x\mathbf{x}x
      • 合起来 Ax=LUx=L(Ux)=Lz=yA\mathbf{x} = LU\mathbf{x} = L(U\mathbf{x}) = L\mathbf{z} = \mathbf{y}Ax=LUx=L(Ux)=Lz=y
      • 两步都是三角方程组，都很好解
      • 注意拼接布局的细节：对角线那一格存的是 UUU 的对角元素，LLL 的对角恒为 1 不存
        • 前代解 Lz=yL\mathbf{z} = \mathbf{y}Lz=y 时对角系数按 1 算
        • 回代解 Ux=zU\mathbf{x} = \mathbf{z}Ux=z 时才用 UUU 的对角元素做除数

    • 3.6 顺带得到行列式

      • det⁡A=det⁡(LU)=(det⁡L)(det⁡U)\det A = \det(LU) = (\det L)(\det U)detA=det(LU)=(detL)(detU)

      • 下三角和上三角矩阵的行列式就是对角元素的乘积

      • 这里 det⁡L\det LdetL 恰好等于 1（对角线全是 1），所以

        det⁡A=(U 的对角元素的乘积)\det A = (\text{U 的对角元素的乘积})detA=(U 的对角元素的乘积)

      • 有选主元时：det⁡A=(det⁡P)(det⁡U 的对角元素乘积)\det A = (\det P)(\det U \text{ 的对角元素乘积})detA=(detP)(detU 的对角元素乘积)

        • det⁡P=+1\det P = +1detP=+1（选主元次数为偶数）或 −1-1−1（奇数）

    • 3.7 利用LU分解求逆矩阵

      • 把 A−1=X=(x1,…,xn)A^{-1} = X = (\mathbf{x}_1, \dots, \mathbf{x}_n)A−1=X=(x1​,…,xn​) 按列分块
      • AX=IAX = IAX=I 写成 A(xi,…,xn)=(e1,…,en)A(\mathbf{x}_i, \dots, \mathbf{x}_n) = (\mathbf{e}_1, \dots, \mathbf{e}_n)A(xi​,…,xn​)=(e1​,…,en​)
      • 每个等式 Axi=eiA\mathbf{x}_i = \mathbf{e}_iAxi​=ei​ 都是一个解线性方程的问题
      • 左边完全相同，右边不同 → 只需做一次 LU 分解，之后一劳永逸
      • 但实践中往往不需要整个 A−1A^{-1}A−1，只需要 A−1yA^{-1}\mathbf{y}A−1y
        • 那就直接解 Ax=yA\mathbf{x} = \mathbf{y}Ax=y，运算量更小，也避免累积误差

  • 为什么 LU 分解值得单独一章

    • 一次分解，多次使用
      • 解 nnn 个不同右端的方程组：消元只做一次
      • 求行列式：只算 UUU 的对角乘积
      • 求逆矩阵：对每一列标准向量解一次
    • 这就是「把昂贵的部分提前做掉」的典型

数值计算里的两个细节

选主元不是为了正确性，而是为了稳定性。

消元时如果主元很小（但不是 0），除法会把舍入误差放大。选绝对值最大的行做主元，能让后续计算的相对误差保持在可接受范围内。代价是要额外维护一个置换矩阵 PPP，以及把 PTyP^T\mathbf{y}PTy 算一遍（只是重排分量，很便宜）。

LU 分解在书中的位置

这一章在书里的标题是「计算机上的计算（1）」，说明作者把它定位成从数学到工程的转折点：

  • 第 1、2 章是数学：矩阵是什么、映射是什么、解有什么性质

  • 第 3 章开始是计算：怎么在有限精度下真的把它算出来

  • 第 4 章（特征值、对角化）继续这条路：判断系统会不会「失控」

上一节我们看到，Ax=yA\mathbf{x} = \mathbf{y}Ax=y 只要做一次 LU 分解就能解很多次。而当 y\mathbf{y}y 会随时间变化时，问题就变成了「AtA^tAt 会不会爆炸」，这就需要第 4 章的特征值工具。
