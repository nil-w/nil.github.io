第四章 数学归纳法

  • 什么是数学归纳法？

    • 数学归纳法 是证明某个断言对 0 以上的所有整数都成立的方法
    • 整数有无穷多个，但只要 2 个步骤就能证明关于无穷的命题
    • 课前的比喻：多米诺骨牌。推倒第 1 个 + 推倒第 1 个能带倒第 2 个 = 推倒一整排

高斯求和

  • 思考题（存钱罐里的钱）

    • 第 1 天投入 1 元，总金额 1 元
    • 第 2 天投入 2 元，总金额 1 + 2 = 3 元
    • 第 3 天投入 3 元，总金额 1 + 2 + 3 = 6 元
    • 第 4 天投入 4 元，总金额 1 + 2 + 3 + 4 = 10 元
    • 每天都这样投入，第 100 天时总金额是多少？

  • 小高斯的解答

    • 顺次算的结果和逆向算的结果相等，把两串数字纵向相加

    • 100 个 101 相加 = 101 x 100 = 10100，这是要求的数的 2 倍

    • 除以 2，答案 5050

  • 讨论一下小高斯的解答

    • 求 1+2+3+…+100 相当于计算阶梯型瓷砖块数
    • 高斯又做了一个一模一样的阶梯，两者合二为一组成长方形
    • 长方形纵向 101 块横向 100 块，共 10100 块，所求的就是它的一半
    • 计算效率的差别：加到 100 亿，机械相加要 300 年，高斯方法只要 1 乘 1 除

  • 归纳

    • 高斯用的等式：1 + 2 + 3 + … + 100 = 100 x 101 / 2

    • 用变量 n 把「1 到 100」归纳成「1 到 n」

    • 这个等式对 0 以上的任意整数 n 都成立吗？这种时候就要用到数学归纳法了

什么是数学归纳法

  • 0 以上的整数的断言

    • 例 1：断言 A(n)：n x 2 为偶数
      • A(0)：0 x 2 = 0 是偶数，为真
      • A(1)：1 x 2 = 2 是偶数，为真
      • 0 以上的任意整数乘以 2 都是偶数，所以对所有 n 都成立
    • 例 2：断言 B(n)：n x 3 为奇数
      • B(0)：0 x 3 = 0，0 不是奇数，为假
      • 断言不是对所有 n 都成立

  • 步骤

    • 步骤 1：证明 P(0) 成立 —— 叫 基底（base）
    • 步骤 2：证明「若 P(n) 成立，则 P(n+1) 也成立」—— 叫 归纳（induction）
    • 两个都证明了，就证明了 P(n) 对 0 以上的所有整数成立

  • 试着征服无穷数列

    • P(0) 成立（步骤 1）→ P(1) 成立（P(0) + 步骤 2）→ P(2) 成立 → P(3) 成立……
    • 这样循环往复，P(n) 对任意 n 都成立
    • 哪怕 n = 10000000000000000，机械地反复执行步骤 2 终究也能证明
    • 就是「推倒多米诺骨牌」：推倒第 0 个 + 推倒第 k 个能带倒第 k+1 个

  • 用数学归纳法证明高斯的断言

    • 断言 G(n)：0 到 n 的整数之和与 n x (n + 1) / 2 相等
    • 步骤 1（基底）
      • 证明 G(0) 成立
      • 0 到 0 的整数之和是 0，0 x (0 + 1) / 2 也是 0
    • 步骤 2（归纳）

      • 假设 G(k) 成立，即 0 + 1 + 2 + … + k = k x (k + 1) / 2

      • 要证明 G(k+1)：0 + 1 + 2 + … + k + (k+1) = (k+1) x (k+2) / 2

      • G(k+1) 的左边用 G(k) 展开

      • G(k+1) 的右边 = (k+1) x ((k+1) + 1) / 2 = (k+1) x (k + 2) / 2

      • 两边结果相同，从 G(k) 到 G(k+1) 推导成功

求出奇数的和

  • 奇数的和

    • 请证明断言 Q(n) 对 1 以上的所有整数 n 都成立
    • 断言 Q(n)：1 + 3 + 5 + 7 + … + (2 x n - 1) = n²

  • 先用较小的 n 判断真假

    n 左边 右边 n²
    1 1 1
    2 1 + 3 = 4 4
    3 1 + 3 + 5 = 9 9
    4 1 + 3 + 5 + 7 = 16 16
    5 1 + 3 + 5 + 7 + 9 = 25 25

  • 通过数学归纳法证明

    • 步骤 1（基底）
      • 证明 Q(1) 成立：2 x 1 = 1²，成立
      • 这次是「1 以上的」，把 0 换成 1 做基底就能用数学归纳法
    • 步骤 2（归纳）

      • 假设 Q(k) 成立，即 1 + 3 + 5 + … + (2 x k - 1) = k²

      • 要证明 Q(k+1)：1 + 3 + … + (2xk - 1) + (2x(k+1) - 1) = (k+1)²

      • Q(k+1) 的左边用 Q(k) 展开

      • Q(k+1) 的右边 = (k+1)²，两边相同，归纳成立

  • 用代码验证

黑白棋思考题

  • 思考题（黑白棋子的颜色）

    • 假设 n 为 1 以上的整数，用数学归纳法证明断言 T(n) 对 1 以上的所有整数都成立
    • 断言 T(n)：投掷 n 枚黑白棋子，所有棋子的颜色一定相同
    • 提示：不要为图所惑

  • 思考题答案

    • 步骤 1 没问题：棋子只有 1 枚，颜色当然只有 1 种

    • 问题出在步骤 2 的图上：把 n+1 枚棋子分成两组各 k 枚，两组共有的棋子有 k-1 枚

    • k = 1 时共有的棋子数是 1 - 1 = 0，不存在同属于两个组的棋子，图根本不成立

    • 真正的反例：3 枚棋子可以是 黑白黑

    • 图虽然方便，但光靠图来解题是可能存在问题的

编程和数学归纳法

  • 通过循环表示数学归纳法

    • 程序员把证明当编程来考虑可能更容易理解
    • C 的 prove(n) 函数：先在步骤 1 打印 P(0) 成立，然后 while 循环里让 k 逐次递增 1，每次打印「若 P(k) 成立则 P(k+1) 成立」
    • C 语言的 int 有大小限制，实际上不能做无穷的证明，但从结构上能看出反复执行步骤 2 就能证明 P(0) 到 P(n)

  • 循环不变式

    • 循环不变式（loop invariant） 是每次循环都成立的逻辑表达式

    • 循环不变式相当于用数学归纳法证明的「断言」

    • 写循环时想一想「这个循环的循环不变式是什么」就能减少错误

    • 例子：求数组元素之和

    • 断言 M(n)：数组 array 的前 n 个元素之和，等于变量 s 的值

    • 第 4 行 s 初始化为 0，所以 M(0) 成立 —— 相当于步骤 1

    • 第 8 行把 array[k] 加入 s，所以 M(k+1) 成立 —— 相当于步骤 2

    • 第 10 行 k 递增 1，所以 M(k) 成立 —— 为下一步处理设定 k 的值

    • 最后 M(size) 成立，因为 while 里 k 一直递增且一直满足 M(k)

    • M(size) 成立说明 sum 函数没问题，所以 return 返回结果

    • 「若 P(k) 成立则 P(k+1) 成立」翻译成代码，就是「以 P(k) 为前提算出 P(k+1)」

    • 当初想不明白的地方，是把 prove 的输入参数 n（目标阶梯）和本地变量 k（途经阶梯）混为一谈了
