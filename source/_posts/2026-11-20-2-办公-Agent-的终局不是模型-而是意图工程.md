## 任务拆解决定 Agent 能否开工

我最初把办公 Agent 的可靠性看成模型能力问题。模型能理解需求、调用工具、生成结果，就足够完成工作。后来我反复做 Hermes Agent，真正拖慢进度的却是另一件事：系统经常知道用户想做什么，却无法把目标拆成可执行、可验证的步骤。

“整理一份项目周报”看起来只有一句话。落到系统里，至少要分成查找项目资料、筛选本周进展、核对风险、生成草稿、发送前确认。每一步还要规定输入、输出和失败条件。少一个边界，Agent 就可能把旧数据拼进新周报，或者直接发出一份未经确认的内容。

这和我在低代码平台、流程引擎和权限管理里遇到的问题很像。页面和模型提供的是能力，流程定义才决定系统会不会走错路。办公 Agent 也一样。模型再强，也不能替代任务状态、完成条件和异常分支。

<span class="hl">可靠办公 Agent 的第一步，是把模糊目标改写成有状态、有完成条件的任务链。</span>

任务拆解还有一个常被忽略的部分：哪些步骤可以自动执行，哪些步骤必须让人确认。发送邮件、删除文件、修改权限，不该沿用普通查询的执行策略。办公场景的可靠性，来自对动作边界的明确约束。

> 周报任务可以自动生成草稿，发送动作必须等待确认。把两者混在一个提示词里，系统就很难稳定运行。

我到现在也没有一套通用拆解法。任务类型不同，状态定义会变。通用框架最多给出方向，真正可用的规则仍要进入具体业务。

## 上下文决定 Agent 能否做对

我做过 mem-md，也维护过 MemPalace。一个很具体的教训是：记忆系统即使存了内容，也可能找不到当前任务真正需要的那部分。

mem-md 的召回命中率约为 9%。这个数字并不好看，也暴露了文件系统式记忆方案的实际短板。上下文一多，Agent 很容易抓住名字相近的文件，却漏掉真正相关的约束。

> 搜到资料不代表理解任务。找错一份旧方案，比暂时找不到资料更危险。

上下文工程至少要解决三个问题。当前任务需要什么，历史记录里哪些内容仍然有效，什么信息缺失时必须发问。《大模型入门 04｜上下文工程与 Agent 可靠性》已经讨论过模型层面的上下文组织。对办公 Agent 来说，这还不够。

任务上下文要跟着执行状态变化。每完成一步，Agent 都应知道已有结果、未完成事项和失败原因。否则，它会在第二轮重新搜索，或者重复执行已经完成的动作。相关状态必须进入每一步，而不能只留在最初那段需求里。

我还注意到，办公 Agent 的竞争正在从“能对话”转向“能执行”。公开资料里对 Agent 的讨论也更强调工具使用和工作流。这个变化符合我的实践：用户不会长期欣赏一个解释得很漂亮的回答。他们更关心文件有没有更新、权限有没有收紧、消息有没有准确发出。

<span class="hl">上下文的质量不看装了多少信息，而看当前动作能否只依赖正确的信息。</span>

因此，记忆、检索和上下文组装不能分开建设。记忆负责保存，检索负责筛选，上下文负责把此刻真正需要的内容送到模型面前。任何一环偏差，结果都会漂移。

## 权限闭环决定 Agent 能否交付

办公 Agent 的终局不会由一次任务的成功率决定。长期使用后，用户更在意三件事：它做错过什么，它能看见什么，它未经确认能做什么。

这要求权限控制进入执行闭环。读取信息、修改内容、对外发送，应采用不同授权等级。临时查询可以自动执行，敏感读取需要留痕，影响外部系统的动作需要二次确认。每次授权还要有时间范围和资源范围，不能把一次批准变成永久通行证。

我以前做权限管理时，很容易把它理解为后台配置页面的功能。Agent 出现后，这个看法需要更新。权限不再只是界面上某个人能否勾选某项功能，而是模型每生成一个动作时，系统能否根据当前任务、当前资源和当前授权作出判断。

> 一次授权只能覆盖一次明确动作。把“允许发送”扩展成“允许以后发送”，是办公 Agent 最危险的权限漂移。

闭环还需要回执。Agent 执行工具后，要记录请求、授权、结果和异常。用户应该能知道改了什么，也能撤销尚未完成的动作。飞书卡片、审批流和日志系统，都可以承担这种回执与控制职责。

我还关注模型路由，但它只解决执行引擎的选择。上周在《多模型路由只是入口，办公 Agent 胜负取决于意图理解》里，我写下“多模型接入能解决‘用哪个模型’，解决不了‘用户到底想做什么’”。这次我的判断更具体：意图还要被翻译成任务状态、上下文边界和权限动作，三者缺一不可。

<span class="hl">意图工程负责让系统理解目标，权限闭环负责让系统承担后果。</span>

这两个层次共同决定办公 Agent 能否交付。模型能力决定它偶尔能走多远，系统设计决定它每天能否稳定工作。接下来的问题也许更尖锐：当 Agent 可以读资料、调工具、发消息时，我们究竟应该把哪些决定继续留给人类，哪些决定可以安全交出去？
