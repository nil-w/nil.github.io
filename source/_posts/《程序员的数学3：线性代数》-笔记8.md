# 可对角化与特征值

<!--more-->
- 4.4 可对角化的情况

  - 三种表达方式

    - **变量替换**：把「原来的变量」换成「好的变量」，逐个击破
    - **坐标变换**：$\mathbf{y}(t) = C\mathbf{r}(t)$，其中 $C$ 是变换矩阵
    - **乘方计算**：$A^t = PD^tP^{-1}$

  - 用矩阵语言表达坐标变换

    - 原问题 $\mathbf{r}(t) = A\mathbf{r}(t-1)$
    - 令 $\mathbf{y}(t) = C\mathbf{r}(t)$，则变成 $\mathbf{y}(t) = C A C^{-1}\mathbf{y}(t-1)$
    - 如果 $C A C^{-1} = D$ 是对角矩阵，问题就归结为 4.3 的标量情形
    - 还原时用 $\mathbf{r}(t) = C^{-1}\mathbf{y}(t)$

  - 为什么不能用初等变换

    - 通过初等行/列变换确实能把 $A$ 变成 $\mathrm{diag}$ 形式
    - 但初等变换是在 $A$ 的**左右两边分别**乘以可逆矩阵 $C$ 和 $P$，得到 $CAP = D$
    - 而这里的变量替换要求：**左边的 $\mathbf{r}(t)$ 和右边的 $\mathbf{r}(t-1)$ 必须经过同一个 $P$ 变换**
      - 即 $\mathbf{r}(t) = P\mathbf{y}(t)$ 在递推式两边同时生效
    - 所以初等变换在这里不适用 —— 这是第 2 章里「无所不能」的初等变换在本章失效的原因

  - 4.5 特征值、特征向量

    - 几何意义

      - 乘以 $A = \begin{pmatrix} 1.3 & 0 \\ 0 & 0.3 \end{pmatrix}$ 之后，**只有长度的伸缩变化而方向保持不变**的向量就是 $A$ 的特征向量
      - 伸缩倍率就是特征值（伸长时为 1.3，缩短时为 0.3）

    - 定义：满足 $A\mathbf{p} = \lambda \mathbf{p}$ 的非零向量 $\mathbf{p}$ 是特征向量，$\lambda$ 是对应的特征值

    - 旋转矩阵没有实特征向量

      - $A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ 把 $(1,0)^T$ 转到 $(0,1)^T$，把 $(0,1)^T$ 转到 $(-1,0)^T$
      - 对应「以原点为中心逆时针旋转 90 度」的变换
      - 所有向量都转了 90 度，方向不变的向量找不到 → **实数范围内没有特征向量**
      - 引入复数后就有了：特征值 $+i$ 的特征向量 $\mathbf{p}_+ = (1, i)^T$，特征值 $-i$ 的是 $\mathbf{p}_- = (1, -1)^T$
      - 所以**即便是实矩阵，特征值和特征向量也可能是复数**

    - 复特征值的情况

      - 一般的实方阵 $A$（若可对角化）用实矩阵 $P$ 变换后得到分块对角的实矩阵 $D$
      - 每个 $2 \times 2$ 区块对应一对共轭复特征值
      - 求分块对角矩阵的幂，只需对各区块分别求幂

## 特征值的两种理解

**第一种：伸缩倍率。**

$A\mathbf{p} = \lambda\mathbf{p}$ 意味着沿 $\mathbf{p}$ 这个方向，映射只做伸缩。$\lambda > 1$ 伸长，$|\lambda| < 1$ 缩短，$\lambda < 0$ 伸缩加翻转。

**第二种：系统失控的判据。**

第 4 章的真正目标是判断 $\mathbf{r}(t) = A\mathbf{r}(t-1)$ 会不会失控。如果 $A$ 可对角化成 $A = PDP^{-1}$，那么

$$
A^t = P D^t P^{-1}
$$

失控与否完全由 $D$ 的对角元素决定，也就是**由 $A$ 的特征值决定**：

- 存在 $|\lambda| > 1$ → 失控
- 所有 $|\lambda| < 1$ → 不失控
- 所有 $|\lambda| \le 1$ 但有 $|\lambda| = 1$ → 仅凭特征值无法判断

这个判据是全书最有实用价值的结论之一：不用算完整的 $A^t$，只要算出特征值。

## 为什么特征值是「固有的」

书中明确指出：$D$ 的对角元素本质是**特征方程的解**，是矩阵本身的固有性质，没有任何人为操作的余地。

这解释了为什么变量替换得到的 $D$ 的对角元素是确定的 —— 你换基底、换变量方式都不会改变它们。换句话说，**特征值是矩阵的不变量**。

## 用 Ruby 验证

```ruby
def mat_mul_v(a, v)
  a.each_index.map { |i| a[i].each_index.sum { |j| a[i][j] * v[j] } }
end

# A = [[2,1],[1,2]] 的特征值是 3 和 1
a = [[2.0, 1.0], [1.0, 2.0]]

# 特征向量满足 A*v = lambda*v
[3.0, 1.0].each do |lam|
  # 解 (A - lambda I) v = 0，取 v = (1, -(2-lambda))
  v = [1.0, -(2.0 - lam)]
  r = mat_mul_v(a, v)
  ratio = r.map { |x| x / v[0] }
  puts "lambda=#{lam}  v=#{v}  A*v=#{r.map { |x| x.round(6) }}  比值=#{ratio.map { |x| x.round(6) }}"
end
```

输出：

```
lambda=3.0  v=[1.0, 1.0]  A*v=[3.0, 3.0]  比值=[3.0, 3.0]
lambda=1.0  v=[1.0, -1.0]  A*v=[1.0, -1.0]  比值=[1.0, -1.0]
```

「比值」那两列就是验证：$A\mathbf{p}$ 的每个分量除以 $\mathbf{p}$ 的对应分量，两个都等于 $\lambda$，说明 $\mathbf{p}$ 确实是特征向量，$\lambda$ 确实是伸缩倍率。

顺带验证幂矩阵：

```ruby
def mat_mul(a, b)
  n = a.size
  m = b[0].size
  k = b.size
  n.times.map { |i| m.times.map { |j| k.times.sum { |t| a[i][t] * b[t][j] } } }
end

def mat_pow(a, e)
  r = a.size
  res = Array.new(r) { |i| Array.new(r) { |j| i == j ? 1.0 : 0.0 } }
  base = a
  while e > 0
    res = mat_mul(res, base) if e & 1 == 1
    base = mat_mul(base, base)
    e >>= 1
  end
  res
end

a = [[2.0, 1.0], [1.0, 2.0]]
p3 = mat_pow(a, 3)
puts "A^3 = #{p3.each_index.map { |i| p3[i].map { |v| v.round(6) } }}"  # A^3 = [[14.0, 13.0], [13.0, 14.0]]
```

$A^3 = P D^3 P^{-1}$ 这个公式可以用来交叉验证求出的 $P$ 和 $D$ 是否正确。

## 从特征值到 Jordan 标准型

特征值判据有个漏洞：**$|\lambda| = 1$ 的情况，仅凭特征值无法判断**。

原因是当 $A$ 不可对角化时，$A^t$ 里有 $t$ 这个因子出现。一个 $\lambda = 1$ 的 Jordan 块，其 $t$ 次方带上 $t$ 的增长，$t$ 无限增大时还是会发散。

这就是下一节（4.7 不可对角化的情况）要解决的问题：**用 Jordan 标准型补上这个缺口**。
