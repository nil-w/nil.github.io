## 自带钥匙的客户端才谈得上选择

少数派 11 月 26 日那篇 App+1 介绍 Agora，独立开发者 Newo Ether 做的，在 F-Droid 上能找到。作者是长期用小米 MiMo 的少数派用户，先用 Kimi Code 被 5 小时限额卡在半路，才转去用 API 远程调用。

桌面端这类工具早就有了，ChatBox、Jan，开箱即用还跨平台。Android 端几乎是空白，能找到的开源产品只有 oxproxion（只能接 OpenRouter，界面也不友好）和 GPTMobile（界面友好，但只支持 OpenAI、Anthropic、Google 三家）。作者在 F-Droid 换了多轮关键词才翻出 Agora。

<span class="hl">入口掌握在自己手里，模型才谈得上随时换。</span>

自带密钥这条路的价值我比作者看得更重。我做 Hermes Atlas 知识库，卡在三个问题上：解决什么问题，谁付钱，怎么收钱。这三件事一个都算不出来，而模型选择是可以算的——每天用什么、多少钱、换一家贵不贵。

> 内置 8 家提供商，加自定义兼容 OpenAI、Anthropic、Google 的接口，再加本地 GGUF。三套来源装在一个应用里。

《主权AI不是护城河，控制平面才是独立开发者机会》（2026-11-24）那篇我写过控制平面有多重要，Agora 是这条判断的一个具体样本：客户端不归你，你的模型清单就不归你。

## 配置比使用更费事

Agora 支持三类提供商。内置的 8 家主流提供商里包括 Google、OpenAI、Anthropic、DeepSeek，还有第三方平台 OpenRouter，填个 API Key 就能用。自定义提供商针对兼容 OpenAI、Anthropic、Google 接口的服务，填服务器地址和密钥即可，小米的 MiMo 就是走这一条补进去的。本地模型则是导入 GGUF 文件，用它内置的 llama.cpp 在设备上跑。

还有一步容易漏。提供商配好不等于能用，还要进模型页点「从所有提供商同步」，再逐个勾选要用的模型。作者加了 MiMo 的按量计费和 Token Plan 两个提供商，API 地址不同所以算两个，下面能拉到小米给的 7 个模型，聊天只勾了 V2.6 Flash 和 v2.6 Pro。

> Claude Opus 每百万 token 输入 4 美元、输出 20 美元，缓存命中 0.20 美元。Fable 是输入 8 美元、输出 40 美元。误选一次，账单自己会长。

按需启用这一层看着琐碎，实际是在挡刺客。作者提醒费率偏高的模型别顺手勾上，语音这类模型也别混进来。

<span class="hl">把选择权留在自己手里，比多一个默认选项更值钱。</span>

## 本地模型能跑起来，还不算能用

这部分我原本最期待，实际结果泼了盆冷水。作者的手机是一加 13，24GB RAM 加 1TB 存储，比在售新机的 16GB 顶配还大。他选了 Qwen3 8B 的 Q8_0 量化版，把模型控制在 10 GB 以内。

结果模型吐字只有不到 3 tok/s，比放幻灯片还慢。把上下文调到 65536，内存占用直接飙升，ColorOS 的保护机制直接把 Agora 终止了。默认值 16384 是作者建议的起点。

> 8B 模型 Q8_0 量化跑在 24GB 手机上，实测不到 3 tok/s。上下文拉到 65536，ColorOS 直接把应用杀了。

最欠缺的是调优入口。Agora 用的是 llama.cpp，却不给相关设置项，指定 OpenCL 后端、调 GPU 卸载层数、开 Fast Attention 这些都做不到，版本号也不在关于页面里显示，更不能像 Jan 那样自定义 llama.cpp 版本。默认参数想吃遍所有 Android 设备，结果就是兼容性靠运气。

## 沙箱和搜索是我真正想要的

比本地模型更实在的是附件解析。纯文本和 PDF 原生支持，Word 和 Excel 要开「本地沙箱」——基于 Alpine Linux，文件传进去后由模型自己判断格式、选工具、写命令解决。DOCX 本质是 ZIP，模型会用 unzip 解压，再从 XML 里取正文。装个 Python 就能覆盖大部分格式，沙箱管理里也能自己装 Alpine 软件包。

搜索是开箱即用的，内置 web_search 和 web_fetch，默认接 6 种搜索引擎，DuckDuckGo 免费，Brave、Tavily 要自己的 Key，SearXNG 可以自部署，结果最多取 10 条。

> 这些细节决定工具是能上手还是卡在门口：沙箱让附件能读，搜索让答案能落地，分支对话让长对话不被污染。

对话搜索默认是关键词检索，可以自己调最大检索数量、相似度阈值和上下文字数；语义检索在 v2.2.0 还用不了。上下文满了会做结构化总结，超出窗口的内容用变暗的颜色标出来，比悄悄丢掉强。Skill 目前只能从本地导入 Markdown，不能读取关联的其他文件。

我给模型接记忆层折腾了很久，MemPalace 和 Memory Provider 都在这套链路上。Agora 把记忆管理和对话搜索都做成了开关，但那个「每轮都记住你」的默认状态我没有开——我更希望上下文由我自己决定切在哪一刀。

我还在做 Hermes Atlas 知识库，白天是白领，业余时间能连续投入的时间有限。Agora 给我的启发不是「在手机上跑大模型」，而是把入口的形状掌握在自己手里这件事，在手机上同样成立。
