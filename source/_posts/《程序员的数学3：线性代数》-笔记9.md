# 不可对角化的情况与 Jordan 标准型

<!--more-->
- 4.7 不可对角化的情况

  - 为什么需要这一节

    - 对于可对角化的 $A$，判断 $\mathbf{r}(t) = A\mathbf{r}(t-1)$ 或 $\mathbf{r}(t) = e^{At}$ 有没有失控危险，只要考察特征值即可
    - 大多数情况下 $A$ 都可对角化，所以前面的方法已经解决了大部分问题
    - 但某些特殊的**不可对角化**的 $A$，前面的方法行不通

  - 先给结论

    - 离散时间系统 $\mathbf{r}(t) = A\mathbf{r}(t-1)$
      - 存在特征值 $|\lambda| > 1$ → 有失控危险
      - 所有 $|\lambda| < 1$ → 不会失控
      - 所有 $|\lambda| \le 1$ 但存在 $|\lambda| = 1$ → **仅凭特征值无法判断**
    - 连续时间系统 $\mathbf{r}(t) = e^{At}\mathbf{r}(0)$
      - 存在 $\mathrm{Re}(\lambda) > 0$ → 有失控危险
      - 所有 $\mathrm{Re}(\lambda) < 0$ → 不会失控
      - 存在 $\mathrm{Re}(\lambda) = 0$ → **仅凭特征值无法判断**
    - 结论大体不变，差别只出现在「边界上」的情况

  - Jordan 标准型

    - 满足条件的区块称为 **Jordan 块**
    - 一个例子：$J$ 由大小为 5 的 Jordan 块、大小为 2 的、大小为 1 的、大小为 3 的排列而成
    - 对角矩阵也是 Jordan 标准型的一种：**仅含大小为 1 的 Jordan 块的情况就是对角矩阵**
    - 什么样的区块算 Jordan 标准型
      - 对角线上是一堆数
      - 右上方的斜线上全部是 1
      - 但不是随便哪个都行，要满足 Jordan 标准型对区块的要求
      - 书里的例子：$J_1, J_4, J_5$ 是，$J_2, J_3$ 不是
        - $J_1, J_4$ 含 2 个 Jordan 块，$J_5$ 含 1 个，$J_3$ 含 3 个

  - 唯一性

    - 如果不考虑区块的排列顺序，Jordan 标准型**本质上只有一种**
    - 原因：Jordan 块是由 $\mathrm{rank}(A - \lambda I)$ 固定下来的，没有任何灵活变通的余地
    - 这和「对角化本质上是唯一的」是同一回事

  - Jordan 标准型的两个好处

    - 可以看出**特征值、特征向量的样子**
    - 可以进行**乘方的具体计算**

## 那个「无法判断」的边界

这是整节的核心问题，值得单独想清楚。

可对角化时，$A^t = PD^tP^{-1}$，$D^t$ 的每个元素是 $\lambda^t$。$\lambda = 1$ 时 $\lambda^t = 1$，不增长也不衰减，看起来没问题。

但不可对角化时不一样。看最小的例子，$2 \times 2$ 的 Jordan 块：

$$
J = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}
$$

它的特征值是 $1$ 和 $1$（重复），但它**不可对角化**（只有一个线性无关的特征向量）。计算它的幂：

$$
J^t = \begin{pmatrix} 1 & t \\ 0 & 1 \end{pmatrix}
$$

右上角出现了 $t$。系统 $\mathbf{r}(t) = J\mathbf{r}(t-1)$ 展开后是 $J^t \mathbf{r}(0)$，只要 $\mathbf{r}(0)$ 的第二个分量非零，第二个分量就会随 $t$ **线性增长**。

所以 $|\lambda| = 1$ 时：

- 可对角化 → 不失控
- 不可对角化 → 可能线性增长，失控

**光看特征值分辨不出来**，必须知道 Jordan 块的结构。这就是 Jordan 标准型存在的意义。

连续时间情形类似，只是增长从 $t$ 变成 $e^{t \cdot \mathrm{Re}(\lambda)}$，在 $\mathrm{Re}(\lambda) = 0$ 时要看 Jordan 块的层数。

## 用 Ruby 验证 Jordan 块的幂

```ruby
def mat_mul(a, b)
  n = a.size
  m = b[0].size
  k = b.size
  n.times.map { |i| m.times.map { |j| k.times.sum { |t| a[i][t] * b[t][j] } } }
end

def mat_pow(a, e)
  r = a.size
  res = Array.new(r) { |i| Array.new(r) { |j| i == j ? 1.0 : 0.0 } }
  base = a
  while e > 0
    res = mat_mul(res, base) if e & 1 == 1
    base = mat_mul(base, base)
    e >>= 1
  end
  res
end

# 2x2 的 Jordan 块
j = [[1.0, 1.0], [0.0, 1.0]]

[1, 2, 5, 10].each do |t|
  p = mat_pow(j, t)
  puts "t=#{t}  J^#{t} = #{p.each_index.map { |i| p[i].map { |v| v.round(6) } }}"
end
```

输出：

```
t=1  J^1 = [[1.0, 1.0], [0.0, 1.0]]
t=2  J^2 = [[1.0, 2.0], [0.0, 1.0]]
t=5  J^5 = [[1.0, 5.0], [0.0, 1.0]]
t=10  J^10 = [[1.0, 10.0], [0.0, 1.0]]
```

右上角恰好是 $t$。**特征值全都是 1，但矩阵的幂随时间线性增长。** 这就是「仅凭特征值无法判断」的直接证据。

对比一下同样特征值但可对角化的情况：$\mathrm{diag}(1, 1) = I$，它的任何次幂都是 $I$，一点都不增长。

同样是 $\lambda = 1$，两个矩阵的行为天壤之别。差别全在 Jordan 块的结构。

## 什么时候不需要 Jordan 形

实际中大多数时候不需要：

- 只需要判断「会不会失控」的话，先算特征值
- 如果所有 $|\lambda| \ne 1$，特征值就已经给出答案
- 只有当存在 $|\lambda| = 1$（或 $\mathrm{Re}(\lambda) = 0$）时，才需要进一步看 Jordan 块

而更常见的情况是：问题本身就带阻尼（$\mathrm{Re}(\lambda) < 0$），特征值直接告诉你「稳定」，什么都不用多说。

所以 Jordan 标准型更像是一块**补丁**，而不是主线路径。书里 4.7 节把它放在最后，也是这个意思。
